# 优酷定制 SDK 安装方式

适用于本仓库 SDK `6.5.0`。API 以所安装版本的 framework 公开头为准。

[接入概览](../../README.md)

## CocoaPods

以下使用 CocoaPods 官方 trunk 安装固定版本，直接填写 Pod 名称和版本即可。

```ruby
source 'https://cdn.cocoapods.org/'
platform :ios, '11.0'

target 'YourApp' do
  use_frameworks!
  pod 'YKIFLYADLib', '6.5.0'
end
```

```bash
pod install
open YourApp.xcworkspace
```

CocoaPods 会自动投递 `IFLYPlayer.bundle` 并传播 `-ObjC`。

## Swift Package Manager

在 Xcode 中选择 **File > Add Package Dependencies…**，输入公开仓地址：

[https://github.com/LJMcarryu/YKIFLYADLib_iOS.git](https://github.com/LJMcarryu/YKIFLYADLib_iOS.git)

版本选择 **Exact Version** `6.5.0`，将 **IFLYADLib** Product 添加到 App target。这里的 Product 名为 `IFLYADLib`，不是 CocoaPods 的 Pod 名 `YKIFLYADLib`。

GitHub 提供包清单、资源与版本 Tag，TOS 提供二进制下载，不需要 GitHub Release。仓库中的 `Package.swift` 负责声明产品、资源和校验值；实际 XCFramework 由 TOS 地址提供。

SwiftPM 或手动集成时，在最终 App target 的 **Other Linker Flags** 中保留 `$(inherited)` 并添加：

```text
-ObjC
```

在 App target 的 **Link Binary With Libraries** 中加入 `AdSupport.framework`，将 `AppTrackingTransparency.framework` 设为 **Optional**。SwiftPM 自动携带 SDK 资源，无需再从手动包重复拷贝。构建后确认 `Package.resolved` 中该仓版本为 `6.5.0`。

## 手动集成

从 [6.5.0 发布记录](https://download-adsdk.voiceads.cn/ios_sdk/6.5.0/youku/fast-release-record.json) 下载本版本完整包 `YKIFLYADLib-6.5.0.zip`。资产选择如下：

| 用途 | 资产 | 附加内容 |
| --- | --- | --- |
| 手动接入 | `YKIFLYADLib-6.5.0.zip` | 包含 framework 与资源，按下列步骤集成 |
| SwiftPM 二进制 | `IFLYADLib.xcframework.zip` | 由 `Package.swift` 配合资源 target 使用，不作为手动完整包 |
| 校验下载 | `checksums.txt` | 与同版 TOS 下载文件核对 |

解压完整包后：

1. 将 `IFLYADLib.xcframework` 加入 App target，Embed 选择 **Do Not Embed**。
2. 将 `IFLYPlayer.bundle` 加入 **Copy Bundle Resources**。
3. 在 App target 的 `Other Linker Flags` 添加 `-ObjC`。
4. 在 **Link Binary With Libraries** 中添加 `AdSupport.framework`，将 `AppTrackingTransparency.framework` 设置为 **Optional**，以兼容 iOS 11～13。
5. 导入 `<IFLYADLib/IFLYADLib.h>`。确认工程只引用一份 SDK 及对应资源，不要混用不同版本的 framework 和 bundle。

本版完整包：[下载 YKIFLYADLib-6.5.0.zip](https://download-adsdk.voiceads.cn/ios_sdk/6.5.0/youku/YKIFLYADLib-6.5.0.zip)。
